# 路由规则拖拽重排与移动端响应式布局优化

## Goal

在 `web/src/views/RoutingView.vue` 中为路由规则列表引入 `⋮⋮`（GripVertical）把手拖拽排序与序号直跳交互，废除繁琐的单步箭头点击；同时重构移动端响应式布局，在窄屏设备上自适应为流畅紧凑的卡片流（Card Stack），极大提升移动端和长规则列表的排位管理体验。

## Requirements

1. **⋮⋮ 拖拽把手与原生拖拽重排 (Drag-and-Drop Reordering)**
   - 在规则列表每项左侧提供清晰的 `GripVertical`（`⋮⋮`）拖拽把手；
   - 基于 HTML5 原生拖拽机制实现，拖拽过程有清晰的视觉反馈（拖拽悬停位指示线、拖拽中半透明样式）；
   - 松开鼠标后即刻更新响应式 `rules` 数组，无任何闪烁或副作用。

2. **序号设计与精准调位 (Index Badge & Quick Reorder)**
   - 清晰醒目呈现 `#1, #2, #3...` 规则优先级序号徽标；
   - 点击序号即可快速输入目标排位（例如将第 15 位直接输入调整为第 1 位），实现长列表一秒直达，告别繁琐连击；
   - 移除原表格中笨拙冗长的单步箭头按钮（`ArrowUp` / `ArrowDown`）。

3. **移动端响应式自适应 (Mobile Responsive Cards)**
   - 桌面端（`>= sm / 640px`）保留宽屏紧凑表格，新增把手列与序号交互；
   - 移动端（`< sm / 640px`）自动切换为移动端专属卡片流（Card Stack）布局：
     - 顶部横条：左侧 `⋮⋮` 拖拽把手 + 优先级序号徽标 + 目标出站标签 Badge，右侧编辑与删除操作按钮；
     - 内容区域：规整呈现 `vlessRoute`、域名条件、IP 列表、端口及网络协议，文本与标签自适应换行，彻底消除表格横向滚动与布局溢出；
     - 触控优化：操作按钮具备足够的触控区域，交互流畅。

4. **零外部重型依赖与质量门禁**
   - 纯 Vue 3 原生响应式与 Tailwind CSS 实现，不引入重型第三方拖拽库；
   - 前端 Vite 生产构建与类型检查 100% 通过。

## Acceptance Criteria

- [x] 桌面端规则表格首列支持 `⋮⋮` 把手拖拽上下任意重排，松手即完成位次更新。
- [x] 规则优先级序号支持点击快速输入目标位次直接跳转插入。
- [x] 彻底移除原逐行单步箭头按钮，界面清爽精简。
- [x] 移动端（窄屏视口）自动切换为触屏友好的卡片流布局，无横向溢出，包含完整的信息呈现与操作按钮。
- [x] `cd web && mise x -- npm run build` 100% 成功，类型检查与打包零报错。
- [x] 后端编译与测试全绿，不受任何前端交互优化影响。
