# PRD: 用户管理 (UsersView) 控制台风格重构

## 1. 业务目标与愿景
将 `UsersView.vue` 从旧有毛玻璃/渐变大卡片风格重构成“开发者基础设施控制台”（Vercel 骨架 + Linear 密度与中性设计令牌）。
保持现有全部业务功能（包括单人/批量续费、流量重置、状态启停、安全订阅 Token、二维码与多入站节点绑定授权），提供极致清晰的高密度 Table 概览与右侧 Inspector 巡检体验。

## 2. 目标用户与使用场景
- **运维与管理员**：快速检索特定用户、批量管理用户有效期与流量，排查某用户绑定的入站节点及订阅生成是否正常。
- **高频操作**：复制订阅 URL、扫码导入客户端、快速为用户充值/重置流量或延长到期时间。

## 3. 功能需求矩阵

### 3.1 顶部工具栏 (Header & Controls)
- 标题区域：`用户管理` 标题、中性状态徽标（实时热生效说明）；
- 快捷统计栏：用户总数、活跃人数、过期/超额警告；
- 搜索与筛选：
  - 关键字搜索（用户名、UUID、邮箱）；
  - 状态过滤（全部、已启用、已停用、已过期、已超额）；
- 行为按钮：`+ 添加用户`（Primary 按钮，触发右侧新建用户抽屉）。

### 3.2 批量操作条 (Batch Action Bar)
- 当勾选 1 位或多位用户时出现，采用 Neutral 风格浮动/固定操作栏：
  - 显示“已选择 N 位用户”；
  - 快捷批量延期：+30天、+90天、+365天；
  - 批量重置已用流量；
  - 批量启用 / 批量禁用；
  - 批量删除；
  - 取消选择。

### 3.3 主用户表格 (Table-First)
- 列布局：
  1. 复选框（全选/反选当前页）；
  2. 用户名 / 邮箱 / UUID（主副文案结构）；
  3. 授权入站节点（Tags 徽章折叠/紧凑呈现）；
  4. 流量用量与限额（微型进度条 + 百分比文本）；
  5. 有效期与重置周期（支持友好时间显示）；
  6. 状态徽章（Active 绿灯、Disabled 灰灯、Expired 橙灯、Over-quota 红灯）；
  7. 快捷操作列（复制订阅链接、二维码展示、快速编辑、更多下拉）。
- 点击整行唤起右侧 **Inspector 抽屉**。

### 3.4 右侧巡检抽屉 (User Inspector Drawer)
- 顶部：用户名称、状态徽章、关闭按钮；
- 快捷操作工具条：一键复制订阅、查看二维码、编辑配置、启用/禁用开关；
- 核心指标卡：
  - 流量明细（已用、上传、下载、限额、剩余比例）；
  - 账号有效期（剩余天数、到期时间、每月重置日）；
  - 限制设备数与并发；
- 认证信息（只读/可复制）：UUID / 密钥、订阅安全 Token；
- 关联入站节点列表（Inbounds tags 列表及对应端口/协议提示）。

### 3.5 用户创建与编辑表单抽屉 (User Form Drawer)
- 放弃原居中 Modal，改用右侧平滑滑出表单抽屉：
  - 分组 1：基础认证（用户名、密码/UUID、邮箱）；
  - 分组 2：流量配额与周期（总配额 GB、到期时间、每月自动重置日）；
  - 分组 3：高级与权限（最大并发设备数、入站节点权限多选）。

### 3.6 订阅二维码展示 (Subscription Modal/Popover)
- 保持二维码弹窗或紧凑面板，支持一键切换通用订阅、Clash、V2Ray 等格式链接并提供复制。

## 4. 非功能与质量要求
- **零业务回退**：原 API 交互（`fetchUsers`, `addUser`, `updateUser`, `deleteUser`, `batchRenew`, `batchResetTraffic` 等）必须 100% 保持兼容。
- **无依赖引入**：复用已有 UI 原子组件（`Button`, `Input`, `Badge`, `Table*`, `Drawer`），不增加外部组件库。
- **门禁验证**：`cd web && npm run build`（TypeScript 全绿，无构建警告）与 `mise x -- go test ./...` 必须全部通过。
