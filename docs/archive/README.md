# docs/archive — 历史文档封存区

本目录用于**原样封存**已过时或被取代的历史文档，保留项目演进原貌。

## 封存规则

- **原样迁移**：封存 = 将旧文档整体移动到此目录，**不修改任何内容**（保留历史原貌与可追溯性）。
- **只读约定**：封存物仅供对照查阅，后续演进不再回填、不再维护、不再更新。
- **新文档在原路径**：被取代的文档在原路径以新版本整体重写，避免"文档就地漂移"。
- **命名规范**：`<原文件名>.v<旧版本>.md`，版本号取自旧文档标题。
  例：`ARCHITECTURE_AND_LOGIC.v2.0.0.md`。
