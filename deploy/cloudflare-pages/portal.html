如何添加订阅链接？（iOS / Android / 电脑端步骤）
iOS（Shadowrocket / 小火箭等）： 点击右上角「+」➔ 类型选择 「Subscribe / 订阅」（请勿直接点普通节点）➔ 在 URL 栏粘贴订阅链接并保存 ➔ 返回首页选中节点连接。
Android（v2rayNG / Clash Meta / Nekobox）： 打开菜单进入「订阅分组设置」或「配置」➔ 点击「+」新建订阅并粘贴链接 ➔ 保存后点击「更新订阅」拉取全部节点。
Windows / macOS（v2rayN / Clash Verge / FlClash）： 进入「订阅设置 / 配置」➔ 新建订阅并粘贴链接 ➔ 点击「更新订阅」获取最新节点。
如果直接拉取订阅超时或失败： 请展开下方「临时过渡节点」先临时连上网络，再回来更新上方订阅链接即可。
无法拉取订阅？展开临时过渡节点（0 个） 不会自动更新
请勿把临时节点当作日常长期节点使用

以下仅为当前时刻的静态节点快照，后续维护调整后将直接失效且不会自动更新。仅在当前网络无法直接拉取订阅时用于冷启动过渡：

  1. 复制下方临时节点，在客户端选择「从剪贴板导入」并先开启连接；
  2. 联网后，立即回到上方复制「长效订阅链接」并更新订阅，之后切换至订阅节点并删除临时节点。
